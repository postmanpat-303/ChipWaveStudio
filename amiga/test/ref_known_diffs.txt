# Known differences between libxmp 4.6 and ProTracker 2.3 in cwlite-test.mod.
# In each case ptplayer (with the ChipWave Lite changes) does what PT does,
# checked against 8bitbubsy's pt2-clone replayer (src/pt2_replayer.c).
# Format: position row channel kind   (kind: per or vol)
#
# E41 ramp vibrato: PT ramps up first (vibrato2: pos < 128 -> +(pos<<3)),
# libxmp ramps down. Channel 3 keeps the ramp waveform from pos 1 row 0 on.
1 1 3 per
1 2 3 per
1 3 3 per
1 40 3 per
4 1 3 per
# E31 glissando with 3xx/5xy: PT rounds to the first table period <= the
# current one (tonePortNoChange), libxmp to the nearest; on tick 0 PT
# writes the unrounded period (checkMoreEffects default case).
1 10 2 per
1 11 2 per
1 12 2 per
# Tick 0 after a tremolo row: PT doesn't write AUDxVOL on tick 0 without a
# new note, so Paula keeps the last tremolo volume; libxmp reports the base
# volume.
1 10 3 vol
1 11 3 vol
1 12 3 vol
