CHAPTER 12

Saving, loading and exporting

Your song is saved as one .cwt file. Export turns it into a WAV or MP3 you can share anywhere.

The File menu

  • New Ctrl+N, Open… Ctrl+O.
  • Demo songs › opens a ready-made song to explore.
  • Recent › lists your last 20 songs. You can pin favourites.
  • Save Ctrl+S, Save As… Ctrl+Shift+S.
  • Export… (WAV / MP3) Ctrl+Shift+E, Export MP3…, and Quick export WAV… Ctrl+E.
  • Export tracker-compatible copy… saves a copy for ChipWave 0.2.4.0 and older.
  • Instrument library…, Import / Export instrument (.cwi)… and Save / Load controller map…
  • Quit Ctrl+Q.

A • in the window title means there are unsaved changes.

Exporting audio

  1. Format: WAV (32-bit float, lossless) or MP3. For MP3, pick VBR or CBR and the quality with the slider (V2 is about 190 kbps).
  2. Sample rate: 44.1 or 48 kHz.
  3. Range: the whole song, the current block, or the loop region.
  4. Level: normalise to −1.0 dBTP, with the master limiter on.
  5. Tail: extra seconds at the end so echoes and reverb can fade out.
  6. Tags: Edit song info… sets the title, artist and other details saved in the file.
  7. Save to: the file name and folder (normally Music\ChipWave), with Browse…. Then press Export.
IN THIS VERSION Export writes one stereo file of the whole mix. Separate files per track (stems) aren't available yet.

Your work is safe

  • Autosave keeps a safety copy every 2 minutes by default, only when there are unsaved changes. It never overwrites your own file.
  • Backups on save keeps older copies (song.cwt.bak, .bak2 …) each time you save. Choose 0–10 in Settings.
  • If ChipWave ever closes unexpectedly, it offers to bring your work back the next time it starts: Recover, Compare, Discard or Later.

Change all of these in Settings › Files & Safety, which also shows the Recovery folder and the update check.
