CHAPTER 11

Plugins

ChipWave can load CLAP and VST3 plugins, both instruments and effects. They play notes from your clips, go through the mixer and are saved inside your song.

Which plugins work

FormatIn 0.2.17.0
CLAPInstruments and effects. The plugin's own editor opens embedded on Windows, or floating where the plugin offers a floating window.
VST3Instruments and effects. The plugin's own editor opens on Windows. On macOS and Linux, use ChipWave's parameter list instead.
VST2Not supported.
LV2Not supported (not planned yet).

Many plugins ship both a CLAP and a VST3 version. Either works, and the Browser marks each one CLAP or VST3.

Finding your plugins

The first time you start ChipWave, it asks how to find your plugins. You can scan automatically (the standard folders, with an optional deeper search of the drive), choose folders yourself, or skip for now. You can run it again any time from Settings › Plugins › Find plugins… or the Browser's ••• › Find plugins….

SystemStandard folders
Windows%COMMONPROGRAMFILES%\CLAP, %LOCALAPPDATA%\Programs\Common\CLAP and the matching VST3 folders
macOS/Library/Audio/Plug-Ins/CLAP, ~/Library/Audio/Plug-Ins/CLAP and the matching VST3 folders
Linux~/.clap, /usr/lib/clap, /usr/local/lib/clap and ~/.vst3, /usr/lib/vst3, /usr/local/lib/vst3

Keep your plugins somewhere else? Add the folder in Settings › Plugins, then rescan. After you install a new plugin, use the Browser's ••• › Rescan plugins.

FREE INSTRUMENTS Browser › ••• › Get showcase instruments… lists well-known free, open-source instruments such as Surge XT, Dexed, OB-Xf and Odin 2. Tick the ones you want and press Download & install. Each download comes from its creator's own release and is checked before it's installed. When a creator only offers an installer, you get an Open download page button instead.

Using a plugin

  • Open the Browser (Ctrl+B) and pick the VST & CLAP category. Drag a plugin onto the Timeline or a track, or double-click it. Plugins aren't previewed in the Browser.
  • Effect plugins also appear on the Browser's Effects tab, and in the FX chain as Plugin effect.
  • The plugin card has Configure… to open the plugin's own window, Reload to try again after a failure, eight macros you can point at any plugin parameter, and a searchable list of every parameter.
  • The macros can be automated (chapter 9) and MIDI-learned (chapter 10).

Safe scanning

Each plugin is tested in a separate process before ChipWave uses it. A plugin that crashes or hangs can't take ChipWave down with it. Plugins that crash, time out or aren't supported are listed as skipped, with the reason.

MISSING PLUGINS If a song uses a plugin that isn't installed on this computer, the instrument stays in the song as a silent placeholder. Its settings are kept, so nothing is lost when you save. A warning lists the missing plugins when the song opens.
